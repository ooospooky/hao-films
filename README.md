## Design Concept

The site is built around a dark cinematic aesthetic, pure black background, warm white typography, and deep red accents. The intent is to let the work speak first: video reels and project imagery take center stage, while the UI stays minimal and out of the way.

Subtle film-inspired details (scanline textures, timecode style elements) reinforce the filmmaker identity without being decorative noise.

## Stack

React 19 · TypeScript · Vite · TanStack Router · Tailwind CSS v4 · Framer Motion
